# AI-assisted programming disclosure

ChatGPT (OpenAI) assisted with code preparation, portability changes, numerical checking, English documentation and data-visualisation code. Statistical estimates are computed by the explicit Python procedures in this repository from the NHANES data; they are not generated from manuscript prose.

The authors should independently review the code, data definitions, assumptions, result labels and generated outputs before publication. Any manuscript statement that author verification has already occurred should be used only after that verification is completed.

The accompanying manuscript should describe AI assistance in statistical programming and visualisation in its Methods, and writing assistance in the appropriate declaration. See the [Elsevier policy](https://www.elsevier.com/about/policies-and-standards/generative-ai-policies-for-journals).
